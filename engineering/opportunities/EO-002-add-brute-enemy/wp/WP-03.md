# WP-03 — Headless validation and evidence

**Status:** todo · **Depends:** WP-02 · **Refs:** BD-007, INV-2, INV-10, INV-11

## Contract

**Goal.** Prove mechanically that the brute registers, spawns, fights and is
harder to stagger and to kill than its peers — and that nothing else changed.

**Done when.**
1. `node --check` output recorded for every script in `index.html` load order,
   all passing.
2. A harness transcript shows a spawned brute moving through
   `idle → chase → telegraph → attack → recover`.
3. Survivability recorded: identical scripted damage applied to a brute and a
   swordsman, with the hit counts to kill each. The brute's must be higher.
4. Knockback recorded: the same impulse applied to a brute and a knifeman, with
   the resulting `vx` for each. The brute's must be markedly smaller.
5. `git diff --stat` for the whole opportunity recorded, listing exactly three
   paths — proof of conditions C-1 and C-2.
6. The four existing definitions and `enemy.js` confirmed byte-identical to `HEAD`.

**Touches.** No repository file. The harness is throwaway and lives outside the
working tree.

**Forbidden.** Committing the harness, adding a test framework, a `package.json`,
or any dev dependency (STD-03). Tuning any value to make a check pass — if a
check fails, that is a finding, not a licence to edit `brute.js`.

**Must not change.** Anything. This package is read-only with respect to the repo.

## Notes
- **Build the harness the way `project-context/architecture.md` §Verification
  describes:** a `vm` context whose `window` is the sandbox itself; stub
  `document.getElementById('screen')` with a fake canvas whose `getContext`
  returns a Proxy that no-ops every method, special-casing
  `createLinearGradient`/`createRadialGradient` to return `{addColorStop(){}}`;
  then `vm.runInContext` each `src` from `index.html` in order.
  `Phefo.Game.boot()` runs on load; drive it with `Game.step(1/120)`.
- **INV-10 — the trap that will waste your time.** `Combat.applyDamage` refuses
  hits when `target.invuln > 0` or when the target blocks frontally. A scripted
  kill loop that does not reset `invuln = 0`, `blocking = false` and pass
  `dirX = target.facing` will silently apply almost no damage and you will
  conclude the brute is invincible.
- **INV-11.** `Input.CONFIRM` includes `Space`, so simulating a jump from a
  victory or game-over screen restarts the run underneath you. Do not press it.
- **INV-2.** Step at exactly `1/120`. Stepping at a display-ish `1/60` changes
  how many frames a 0.58 s telegraph occupies and makes the transcript lie.
- Compare against **both** peers, not just one: survivability against the
  swordsman (the other heavy), knockback against the knifeman (the light one).
  A single comparison proves less than it appears to.
