# WP-02 — Wave placement in level01_city

**Status:** todo · **Depends:** WP-01 · **Refs:** BD-004, BD-005, INV-7

## Contract

**Goal.** Put the brute into the existing wave progression so a player meets it
alone before meeting it under pressure — without altering any existing encounter.

**Done when.**
1. Wave 3 (the `swordsman/knifeman/archer` wave) gains exactly one
   `{ type: 'brute', x: … }` entry.
2. Wave 5 (the final wave) gains exactly one `{ type: 'brute', x: … }` entry.
3. Every entry that exists today is still present, with its original `type` and
   its original `x`. Nothing is removed, reordered or renumbered.
4. Both brutes stand on the road — `y` is omitted exactly as every existing
   entry omits it.
5. `node --check phefo/js/levels/level01_city.js` passes; the game boots and both
   waves spawn without error.
6. `git diff --stat` lists exactly one path, and the diff contains only added
   lines inside the `waves` array.

**Touches.** `phefo/js/levels/level01_city.js` — the `waves` array **only**.

**Forbidden.**
- `solids`, `pickups`, `bounds`, `playerStart`, `waveDelay`, `decor` and the
  level's header comment — all off limits in this package.
- Every other file in the repository. `brute.js` is finished; if a value needs
  changing, that is a deviation to record, not an edit to make here.

**Must not change.** The difficulty of waves 1, 2 and 4 — they are not touched at
all. Waves 3 and 5 get strictly harder by one enemy, which is the intent.

## Notes
- **INV-7 is why `y` is omitted.** `Enemy.update` only acquires a target within
  120 px of its own height, and every platform in this level sits 128–196 px
  above the road. A brute placed on a platform would stand there inert forever.
  There is already a comment in wave 5 recording exactly this trap for the
  archer — do not add a second one; one is enough.
- **Spacing.** Existing entries are 150–400 px apart and the level runs
  x ≈ 0…2700. Place the wave-3 brute far enough from the swordsman at x 900 that
  the player meets them one at a time, and the wave-5 brute where it blocks the
  approach to the ranged pair rather than arriving alongside them. Keep both
  clear of the crates at 430–534 and the concrete block at 980–1108, which are
  `solid` and would spawn the brute inside geometry.
- Entries are plain object literals in an array, one per line, aligned with the
  existing style. Match the surrounding formatting exactly (STD-01).
